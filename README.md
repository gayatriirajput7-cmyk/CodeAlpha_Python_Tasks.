# CodeAlpha_Python_Tasks.
# CodeAlpha Python Internship Projects

This repository contains the Python programming tasks completed during my Software Development Internship at CodeAlpha. Each project focuses on fundamental Python concepts, including data structures, file handling, and control flow logic.

## Projects Overview

### Task 1: Hangman Game (`hangman.py`)
A classic command-line word guessing game. 
* **Features:** Random word selection, user input validation, mistake tracking, and automatic file saving for match results (`hangman_result.txt`).
* **Concepts Used:** `while` loops, lists, conditional logic, and string manipulation.

### Task 2: Stock Portfolio Tracker (`stock_tracker.py`)
A command-line financial tool to track mock stock investments.
* **Features:** Live calculation of shares, running portfolio total, and export functionality that saves the grand total to `portfolio.txt`.
* **Concepts Used:** Dictionaries for fast data lookups, arithmetic operations, and `with open()` file handling.

### Task 4: Basic Chatbot (`chatbot.py`)
A rule-based conversational agent.
* **Features:** Recognizes basic greetings, answers simple questions, and handles unknown inputs smoothly without crashing.
* **Concepts Used:** `if-elif-else` routing and input sanitization (`.strip().lower()`).
